# Where the verified DOC answers live (2026-09-30)

The public FAQ at play.johnreevesiii.com/faq is the verified answer key for Derby Owners Club game mechanics. Every entry marked confirmed was decoded from the game ROM or measured in the arcade's own data, then re-derived by an independent second pass. DOC Bot answers questions by pointing to the matching FAQ entry. The files in this knowledge base are historical reference: where any of them disagrees with the FAQ, the FAQ wins.

The complete confirmed data set (per game version, with evidence) is on the DOC Drive at knowledge/CONFIRMED/, with open questions in VERIFY-QUEUE.md and cabinet-only questions in CAB-TEST-QUEUE.md.
