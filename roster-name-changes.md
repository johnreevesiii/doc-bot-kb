# DOC roster: horse name changes across versions (`roster-name-changes`)

KEY: roster-name-changes
Status: CONFIRMED (byte-exact, decoded from the ROM rosters of each version)

The DOC breeding roster changed across four versions. In order: **DOC '99** (original, Japanese, 1999), **DOC 2000** (Japanese, 2000), **World Edition / WE** (English export, Rev C), and **World Edition EX / EX** (English, Rev D). The same underlying horse can carry a different NAME in each version. These maps were recovered by matching horses between versions on their exact hidden stats, so a rename is confirmed when two entries share identical stats but differ in name.

## Japanese (DOC 2000) horses and their World Edition names

Sega could not license the real Japanese racehorse names for the Western release, so World Edition renamed the roster. Every plain English WE name below is a real Japanese champion in disguise. 144 horses were renamed; 15 kept their romanized name. ## DOC '99 vs DOC 2000 (both Japanese)

The two Japanese games are mostly different rosters. About 93 horses share a Japanese name across both, but nearly all of them (92 of 93) were re-statted in DOC 2000, and only one horse is identical. So DOC 2000 was not simply DOC '99 plus new horses: it re-tuned almost every returning horse and swapped much of the pool.

## How to answer roster questions

- "What is <Japanese horse> called in World Edition / the English version?" Use the DOC 2000 -> WE table. Example: Oguri Cap is Wild Jaguar; Mejiro McQueen is White Snake; Tokai Teio is Helissio.
- "What did <WE horse> get renamed to in EX?" Use the WE -> EX table. Example: Butter Popcorn became Layin Back.
- Reverse lookups work the same way (both columns are in the tables). Peach Girl (WE) became Lucky Laurie (EX).
- Wild Sun is in BOTH World Edition and EX under the same name (a WE sire, not EX-only).
- These maps are CONFIRMED byte-exact from the decoded rosters, so you can state them plainly. For the few ambiguous mares, say the target is one of two named horses.
